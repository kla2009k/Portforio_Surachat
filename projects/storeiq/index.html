StoreIQ

AI-powered retail analytics สำหรับร้านค้าปลีก SME ไทย

ROLE
PROJECT LEAD / FULL-STACK
STATUS
HACKATHON PROTOTYPE
YEAR
2026
FIELD
DATA / CLOUD SYSTEM

ระบบวิเคราะห์ CSV ยอดขายสำหรับ SME ที่รวม anomaly detection, market basket, แนวโน้มรายได้ และคำอธิบาย insight ด้วย AI ไว้ใน workflow เดียว

CONTEXT / PROBLEM

ปัญหาที่เลือกทำ

ร้านค้าขนาดเล็กมักมีข้อมูลการขายแต่ไม่มีทีมวิเคราะห์ข้อมูล StoreIQ จึงทดลองทำให้ไฟล์ CSV กลายเป็นรายการที่ลงมือทำต่อได้ โดยแยกการคำนวณเชิงสถิติออกจากคำอธิบายภาษาของ AI

OWNERSHIP / CONTRIBUTION

ส่วนที่ผมรับผิดชอบ

วางผลิตภัณฑ์ ออกแบบ dashboard และ workflow วิเคราะห์ข้อมูล พัฒนา frontend/backend และเตรียมสถาปัตยกรรม AWS สำหรับการนำเสนอในบริบท Retail Tech Hackathon

  • 01ออกแบบการนำเข้า CSV และมุมมองยอดขายหลายสาขา
  • 02สร้าง anomaly detection ด้วย Z-score และหน้าค้นหาสาเหตุที่ตรวจย้อนกลับได้
  • 03รวม market basket, trend, revenue และ profit/loss ใน dashboard เดียว
  • 04แยกผลคำนวณออกจาก AI-generated explanation เพื่อลดการเชื่อคำอธิบายเกินจริง

SYSTEM / PROCESS

ระบบและกระบวนการ

  1. 01
    INGEST

    รับไฟล์ CSV และตรวจโครงสร้างข้อมูลก่อนเริ่มวิเคราะห์

  2. 02
    COMPUTE

    คำนวณยอดขาย แนวโน้ม ตะกร้าสินค้า และรายการผิดปกติ

  3. 03
    EXPLAIN

    ส่งเฉพาะบริบทที่กำหนดให้ AI ช่วยอธิบาย insight เป็นภาษาอ่านง่าย

  4. 04
    ACT

    จัดผลลัพธ์เป็น action board เพื่อช่วยผู้ใช้ตัดสินใจว่าจะตรวจอะไรต่อ
